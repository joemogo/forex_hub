SYNTHETIC TEST DATA / NOT REAL TJR RESEARCH / NOT VALIDATED TRADING KNOWLEDGE / NOT A PRODUCTION RULE

Every JSON file under this directory was generated by
`scripts/trader_intelligence/generate_synthetic_evidence_fixture.py` for
PROGRAM-006 Phase 1A (ADR-008, Deliverable 14). None of it is real TJR
research, a validated trading claim, or a production rule. It exists solely
to demonstrate the Evidence Intelligence Engine's data model end to end:

- 1 EvidenceSource (`EVSRC|TJR|...|001`, a transcript) plus 1 corroborating
  EvidenceSource (`EVSRC|TJR|...|002`, an owner observation) -- two sources
  in total, so the confidence engine's cross-source independence-group
  discounting has something real to discount.
- 5 EvidenceItems: a primary explicit statement, a corroborating chart
  example that is corrected once (demonstrating supersession -- the original
  is never edited in place), an independent corroborating statement from the
  second source, and one contradicting opinion.
- 2 Claims: one reaches `confidenceState="supported"` from three supporting
  items across two independent sources; the other reaches
  `confidenceState="contradicted"` from a single unsupported contradicting
  item.
- 1 ContradictionRecord linking the two claims.
- A full lifecycle event history for every entity, including the
  `superseded` event recorded when the chart-example correction was applied.

Regenerate with:

    python3 scripts/trader_intelligence/generate_synthetic_evidence_fixture.py
