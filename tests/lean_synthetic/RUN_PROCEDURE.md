# Operator procedure — synthetic Mode B engine smoke test

**The one question:** does LEAN deliver bars through its own event-driven subscription path
into `on_data`, and does the reviewed state machine consume each one exactly once, in order,
with no bar arriving before its own `EndTime` — for a qualifying case that must decide and a
rejecting case that must not?

**Not** parity, **not** strategy validation, **not** profitability. Places no orders, adds no
broker, holds nothing. Says nothing about the historical 15 cases or the five break-cycle
divergences.

## Why an operator has to run it

No agent credentials exist for the QuantConnect account, and neither the `lean` CLI nor Docker
is installed here, so there is no local engine either. Everything checkable without the engine
has been checked and passes — that is explicitly **not** an engine run.

## Steps — one run, both cases

1. Create a **new** QuantConnect project named `MOGO Synthetic Smoke`.
   **Do not reuse or modify the parity project `35636512` / `Creative Red Panda`.**
2. Upload exactly three files: `main.py`, `br_machine.py`, `synthetic_bars.py`.
   (The CSVs are fetched by LEAN over HTTPS — do not upload them.)
3. Run **one** backtest. No data subscription, no broker, no orders. Free tier is sufficient.

## Exactly what to return

- All **21** `SMOKE-CHECK` lines (10 per case + 1 global isolation check).
- Both `SMOKE-CASE` lines.
- The single `SMOKE-VERDICT` line.
- The **project id**, **backtest name/id**, **algorithm id** and **LEAN version** from the run record.
- Any runtime error text, verbatim, if the run fails.

## Expected output

    SMOKE-CASE SYNQUAL PASS bars=120 state=LOCKED decision=True locked_at=55 failed=none
    SMOKE-CASE SYNREJ  PASS bars=120 state=BROKEN decision=False locked_at=None failed=none
    SMOKE-VERDICT PASS engine=LEAN failed=none

`engine=LEAN` is the algorithm's own runtime detection and is **not sufficient proof on its
own** — it must be corroborated by the platform run record (project/backtest/algorithm ids and
LEAN version), which is why those are requested above.

## If it fails

Return the verbatim error and the `SMOKE-CHECK` lines. The likely first-run failure is the
subscription delivering 0 bars (the symptom every previously-tried transport showed). Do not
adjust the expected answers; the repair belongs in the adapter.
